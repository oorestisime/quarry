Use the reference for exact signatures and behavior. Start with the
[quickstart](/docs/guides/getting-started) for setup or
[recipes](/docs/recipes) for complete queries.

| Task | Reference |
| --- | --- |
| Create a typed database handle | [Database API](/docs/reference/db) |
| Describe read, insert, and predicate values | [Database types](/docs/reference/db-types) |
| Select, join, filter, group, order, and execute | [Select builder](/docs/reference/select) |
| Insert rows or an ordered SELECT result | [Insert builder](/docs/reference/insert) |
| Construct expressions and call functions | [Expressions](/docs/reference/expressions) |

The reference follows development source. Some APIs are not in npm 0.9.1;
[check availability](/docs/releases#published-versus-development) before using a
new method in an existing project. Selected type tables and editor hovers are
built from the library's types.

For SQL coverage, consult the
[ClickHouse support matrix](/docs/concepts/clickhouse-quirks).
For the reasons behind result representations and null behavior, read
[runtime semantics](/docs/concepts/runtime-semantics).
